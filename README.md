# Репетитор — медиа-платформа уроков

Интерактивная страница видео-урока для школьников Алматы (математика и английский).

## Как запустить

1. Откройте папку проекта в терминале.
2. Установите зависимости (если ещё не ставили):

```bash
npm install
```

3. Запустите сайт:

```bash
npm run dev
```

4. Откройте в браузере: [http://localhost:3000](http://localhost:3000)

## Что есть на странице

- Видеоплеер 16:9 с обычными кнопками управления
- Главы (таймкоды) — клик перематывает видео
- Вкладки: Конспект / Материалы и ссылки / Вопросы
- Сайдбар со следующими уроками (активный урок подсвечен)
- Лента комментариев с быстрой отправкой
